# Паритет с tweb: читать базу знаний до кода

Правило проекта (`CLAUDE.md`): вёрстка и поведение берутся **1:1 из tweb**, не выдумываются.
Чтобы не перечитывать исходники tweb каждый раз, в `docs/tweb/` лежат готовые референсы —
7000+ строк с `файл:строка` по tweb и секциями «у нас» с уже найденными расхождениями.

**Никогда не пиши разметку, классы, анимации или поведение по памяти.** Сначала док, потом
исходники tweb (`/Users/denisurevic/Documents/tweb`), потом код.

## Порядок работы

1. **Определи подсистему** и прочитай её док по таблице ниже. Читай не весь файл, а нужные
   разделы (структура заголовков одинакова во всех доках) — целиком каждый док это 20–36 тыс.
   токенов.
2. **Проверь, точечный это фикс или платформа.** Открой `docs/tweb/roadmap.md`:
   если симптом там описан как следствие отсутствующего механизма (навигационный стек,
   базовый попап, слайдер табов, wrappers, конвейер ленты) — скажи об этом пользователю
   до того, как чинить точечно. Точечная починка симптома платформы обычно разъезжается снова.
3. **В исходники tweb** иди только за тем, чего нет в доке; в доке уже есть точные адреса.
4. **Пиши код**, следуя разметке и классам tweb (стили в `web-client/src/styles/tweb/` уже
   портированы глобально — не заводи CSS-модули для того, что там есть).
5. **Обнови секцию «у нас»** в референсе, который использовал, — в том же изменении.
6. **Проверь** до слова «готово»: сборка, тесты, поведение в браузере.

## Если дока нет

Не додумывай по аналогии. Исследуй tweb, **запиши новый док** по конвенциям из
`docs/tweb/README.md` (короткое имя по подсистеме, ссылки `файл:строка`,
секция «у нас» в конце, строка в индексе) — и только потом пиши код. Иначе следующая
задача по этой теме начнётся с нуля.

## Частые ловушки

- **Инлайновый стиль перебивает портированный CSS.** Прежде чем ставить `style={{...}}`,
  проверь, нет ли уже правила в `styles/tweb/` — так уехали sticky-табы shared media.
- **Различия user/group/channel в tweb декларативные**, а не форки: каждая секция профиля
  сама решает, показываться ли. Не плоди ветвления по типу пира.
- **Порядок в DOM вместо `z-index`.** В tweb у попапов, меню и медиавьювера один `z-index: 4`;
  ручные числа 500…9999 — наш долг, не образец.
- **`framer-motion` и MUI удалены** — не возвращать: анимации на CSS-классах tweb.
- **Виртуальный список диалогов уже портирован** (программа из 4 этапов) — не переизобретать,
  спеки в `docs/superpowers/specs/2026-08-1[23]-*`, читать разделы «Отступления».
