  React с тем же зеркалом URL; восстановление скрытой миниатюры — Task 16
  (`onClose`). **`fullPhotoSize`-добор (:2909-2912) не портирован** — у бэка
  один полноразмер, photoSize-лестницы не существует (комментарии у строк).

  manual-ретрая); очередь может понадобиться соседям по листанию в Task 14.

  (appNavigationController) не заводились — Esc/навигация через наш
  navLayer-стек в Task 16 (помечено в _openMedia и close).
