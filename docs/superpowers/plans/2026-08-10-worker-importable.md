# Импортируемый `worker.ts` — Implementation Plan

**Goal:** Сделать корень воркерного бандла импортируемым в тестах, чтобы его проводку можно было проверять по-настоящему, а не текстовым инвариантом.

**Architecture:** Сегодня `src/core/worker.ts` (386 строк) исполняет весь свой body при импорте: создаёт менеджеры, транспорт, funnel, соединение и в последних строках сам себя устанавливает (`g.onconnect` / `bind`). Из-за этого файл неимпортируем в vitest — на верхнем уровне он лезет в IndexedDB. Переходим к форме «фабрика + тонкая точка входа», уже принятой в проекте для `globalFunnel.ts`, `channelFunnel.ts`, `workerScope.ts`.

**Tech Stack:** TS strict, vitest + happy-dom, SharedWorker.

## Зачем

Финальное ревью Этапа 1C.1 вырезало **одновременно** две строки проводки в `worker.ts:bind()` — снятие порта закрытой вкладки (`smp.setOnPortDisconnect(…)` + `indexOfAndSplice(ports, smp)`) и ретрансляцию кадра вкладки (`workerScope.receiveFrom(smp, …)`) — и получило **176 файлов / 1166 тестов зелёными**. То есть вся ценность прополки портов и половина ценности воркерной шины удалялись из прода бесследно.

Дыру закрыли текстовым инвариантом (`worker.bindWiring.test.ts`) — тест читает исходник и требует наличия обеих строк. Это подпорка с известной хрупкостью: разбор тела `bind()` по балансу скобок ломается на трейлинг-комментарии или строковом литерале с непарной скобкой (ре-ревью это воспроизвело). Направление отказа безопасное, но приём остаётся костылём.

Симптом за сессию всплыл трижды: `attachLock` в `bootstrap.ts`, `observeNewSections` в `Chat.tsx`, проводка в `worker.ts`. Каждый раз его ловил ревьюер вручную, а не тест. Причина общая: **проводка живёт в корнях бандлов, а корни неимпортируемы по своей природе** — они и существуют затем, чтобы поднять среду.

## Global Constraints

- **Чистое перемещение.** Ни одна ветка, ни один порядок вызовов, ни одно значение не меняются. Диффом должно быть видно, что это перенос, а не переписывание. Показалось, что «тут логичнее иначе» — не трогать, записать в отчёт как наблюдение.
- **Поведение не меняется.** Все существующие тесты обязаны пройти **без единой правки**, включая `worker.bindWiring.test.ts`. Если правка потребовалась — стоп, BLOCKED, с указанием, какой инвариант поехал.
  Исключение: `worker.bindWiring.test.ts` — текстовая подпорка, ради снятия которой этот план и написан. Его судьба — Задача 2, не Задача 1.
- **Порядок инициализации священен.** В `worker.ts` менеджеры объявлены выше `broadcast`/`workerScope` и получают их **ленивыми стрелками** (комментарии на строках 83, 88, 99, 123). Этот порядок обязан сохраниться дословно; TDZ-ошибки при переносе — реальный риск.
- **`WorkerRegistry` не должен сломаться.** `bootstrap.ts:7` берёт его как `import type { WorkerRegistry } from '../core/worker'` и выводит из него публичный тип `Managers`. Импорт обязан остаться типовым (рантайм-импорт втащил бы воркерное дерево в бандл вкладки).
- Комментарии по-русски, в стиле окружающего кода; при переносе комментарии едут вместе с кодом — они объясняют неочевидное, не выбрасывать и не переписывать.
- Команды из `web-client/`: `npm test`, `npm run typecheck`, `npx oxlint <файлы>`, `npm run build`.
  `npm run lint` выходит с кодом 1 и на main (вендореный `helpers/middleware.ts`) — ворота: не добавлять НОВЫХ находок в изменённых файлах.
- **Git-гигиена:** только точечный `git add <файлы>` + `git commit`. Запрещены `git reset`, `git rebase`, `git commit --amend`, `git checkout`/`restore`, `git stash`, `git add -A`/`.`, `git commit -a`.

### Task 1: Фабрика ядра + тонкая точка входа

**Files:**
- Create: `web-client/src/core/workerCore.ts` (тело нынешнего `worker.ts` внутри фабрики)
- Modify: `web-client/src/core/worker.ts` (остаётся точкой входа на несколько строк)

**Целевая форма.**

```ts
// workerCore.ts
export function createWorkerCore() {
  // …всё нынешнее тело worker.ts: tokens, rest, менеджеры, funnel, conn, registry, bind…
  return { registry, bind, ports, workerScope, start }
}
export type WorkerRegistry = ReturnType<typeof createWorkerCore>['registry']
```

```ts
// worker.ts — точка входа, больше ничего
import { createWorkerCore } from './workerCore'
export type { WorkerRegistry } from './workerCore'

const core = createWorkerCore()
core.start()
```

`start()` содержит то, что сегодня исполняется на верхнем уровне как сайд-эффект:
- `void tokens.load().then(() => persistScope(tokens.get()))` (строка 60);
- `void tokens.ready().then(() => auth.me())…` (строка 81);
- `void cursor.ready().then(() => { cursorReady = true })` (строка 150);
- финальный блок `const g = self as …` + `if ('onconnect' in g) … else bind(g …)` (строки 378-386).

Всё остальное — объявления — переезжает внутрь фабрики как есть.
