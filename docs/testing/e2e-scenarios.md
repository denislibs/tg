# Сквозные сценарии (Playwright): каталог

Решение пользователя 2026-09-27. Тесты **функциональные**: гоняют путь пользователя на нашем стенде и
проверяют результат. Дотошного сравнения DOM с tweb нет — дампы `docs/tweb/dom/dumps/` сняты до tweb
`812502980` и устарели. **Эталон поведения — код tweb 812502980** (`/Users/denisurevic/Documents/tweb`):
у каждого сценария ожидания выписываются из исходников tweb со ссылкой `файл:строка` (заполняется при
реализации сценария). Сверка вёрстки — отдельно, руками и скриптами `tools/tweb-parity`.

## Как устроен сценарий

- **Актёры** — 1–3 браузерных контекста (A, B, C), каждый со своим аккаунтом. Аккаунты и данные тест
  создаёт сам через наш HTTP API (вход — dev OTP `12345`, номера `9990…` с уникальным хвостом), сид
  стенда (`SEED_DEMO`, Алиса `9990000001`) не трогает.
- **Шаги** — действия через интерфейс, как у человека.
- **Ожидания** — что видит каждый актёр: лента, список чатов, шапка, правая колонка, счётчики,
  уведомления; сразу и после F5. Выписаны из кода tweb.
- **Сторожа на каждый шаг** (общие, для всех сценариев):
  - ошибка в консоли браузера → падение;
  - ответ API `4xx`/`5xx`, кроме ожидаемых сценарием → падение;
  - `NaN`, `undefined`, `null` в адресе запроса → падение;
  - спиннер/лоадер дольше N секунд → падение («вечный лоадер»);
  - необработанный reject в воркере → падение.
- **При падении** — скриншот и видео шага, лог сети и консоли.

Приоритеты: **P0** — основной путь пользователя, гоняется на каждый PR; **P1** — частые действия;
**P2** — остальное.

## Порядок работ

1. **Каркас:** Playwright, фикстуры аккаунтов через API, сторожа, отчёт (скриншот/видео/сеть/консоль).
2. **P0** (раздел 0 и P0 из разделов) — гоняется на каждый PR.
3. **Области параллельно** (по агенту на область, свои файлы сценариев); найденные баги — фиксы пачками
   по корню, отдельными PR.
4. У каждого сценария при реализации — ожидания со ссылкой на код tweb `файл:строка`; если у нас
   поведение законно отличается — ссылка на отступление (О-N из планов / `docs/readiness/port-divergences.md`).
